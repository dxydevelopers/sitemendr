# Sitemendr

Sitemendr is a Next.js application with the active frontend living in [`frontend/`](./frontend/). The repository also contains backend source and supporting project files, but the main runnable web app is the frontend package.

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

## Build

```bash
cd frontend
npm run build
```

## Notes

- The frontend is configured to build with webpack in this environment.
- The root-level `package.json` and `package-lock.json` were removed because they were only stale placeholders.
- If you need the app URL locally, open `http://localhost:3000` after starting the dev server.
