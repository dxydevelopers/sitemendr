# Sitemendr: Dashboard "Engine Room" Identity Plan

## **1. The Global Shell (Unified Navigation)**
The dashboard is a single-page application (SPA) environment that maintains a consistent frame while the internal content adapts to the active "Work Mode."

### **Navigation Sidebar (The Command Strip)**
*   **Overview**: Aggregate data from all active protocols.
*   **My Projects**: The primary entry point for active work.
*   **Communication Core**: Unified messaging and specialized support channels.
*   **Financials**: Billing, subscriptions, and investment history.
*   **Knowledge Base**: Service-specific documentation and tutorials.
*   **Rewards Program**: Loyalty tier tracking and perk activation.
*   **Settings**: Secure profile and authentication management.

---

## **2. The Project Context Switcher**
A high-end, visual project selector that allows the client to toggle between different service types.
*   **Visual Indicators**: Each project is tagged by its Pillar (Merchant, Creative, or Technical).
*   **Status Badges**: Real-time progress (e.g., "Consultation Phase," "Building," "Active Monitor").

---

## **3. Specialized Workspaces (The "Actual Work")**

### **A. The Merchant Desk (Dropshipping / E-commerce)**
*   **Visual Content Editor**: A high-fidelity, drag-and-drop interface for real-time storefront refinement (from `visual-editor-architecture.md`).
*   **Strategic Insights**: Algorithmic niche analysis, trending product suggestions, and sales velocity tracking.
*   **Operational Sync**: Inventory health indicators and supplier integration status.

### **B. The Creative Desk (Custom Website Development)**
*   **Interactive Roadmap**: A 5-step visual timeline with granular milestone tracking.
*   **Asset Management**: Secure drag-and-drop area for logos, media, and branding guidelines.
*   **Collaborative Review**: An integrated feedback tool for commenting on design concepts and staging builds.
*   **Technical Specs**: Live access to the project’s architectural blueprint.

### **C. The Technical Desk (Maintenance & Repair)**
*   **Integrity Monitor**: Live uptime, security, and performance health scores.
*   **Audit Logs**: Detailed reports from automated scans and manual remediation sessions.
*   **Security Vault**: A double-encrypted environment for sharing site credentials.
*   **Incident Response**: Rapid-action button for critical system failures.

---

## **4. Shared Utility Modules**

### **The Communication Core**
*   **Contextual Chat**: Messaging is automatically filed under the relevant project.
*   **Ticket Integration**: Technical repairs are managed through a professional ticketing system.

### **The Fiscal Control Center**
*   **Unified Billing**: Managing subscriptions for dropshipping, development installments, and maintenance plans in one view.
*   **Transparency**: Detailed breakdowns of "System Resource" usage and service hours.

### **The Ecosystem Rewards**
*   **Loyalty Points**: Earned through long-term maintenance or referring new clients.
*   **Service Tiers**: Unlocking priority support or expert consulting hours based on ecosystem engagement.

---

## **5. Transition Logic: The 5-Step Progress**
Within each project workspace, the "Project Journey" component tracks:
1.  **Strategy**: Initial data ingestion (Assessment).
2.  **Discovery**: Concept validation and roadmap approval.
3.  **Consultation**: Asset briefing and final contract execution (Payment Gate).
4.  **Building**: Execution phase (Visual Editor for Merchant / Milestones for Creative / Remediation for Technical).
5.  **Launch**: Deployment, handover, and transition to "Active Monitor" status.
